# План сайта «для любимой»

## 1. Техника (бесплатно на GitHub)

| Что | Решение | Почему |
|---|---|---|
| Хостинг | **GitHub Pages** | бесплатно, адрес вида `https://darkhan-fak.github.io/mylove/` |
| Код | чистый **HTML + CSS + JS**, без сборки | GitHub Pages отдаёт статику как есть, ничего не нужно компилировать |
| Данные (хотелки, цели, свидания) | сейчас — `localStorage` (макет); дальше — **Supabase** (бесплатный тариф) | GitHub Pages — только статика: без внешней базы то, что пишет она, не увидишь ты |
| Фото | сейчас — сжимаются и хранятся в браузере; дальше — **Supabase Storage** (1 ГБ бесплатно) | фото сжимаются до ~200–300 КБ, так что места хватит на тысячи |
| Вход | выбор «кто я» на первом экране; дальше — 2 аккаунта в Supabase (вход по ссылке на почту) | чтобы посторонние не могли ничего писать |

Весь доступ к данным идёт через один файл `js/store.js`. Чтобы перейти с `localStorage` на Supabase,
нужно переписать только его, экраны менять не придётся.

## 2. Структура

```
index.html          — единственная страница, экраны переключаются через #адрес
css/style.css       — весь дизайн (цвета задаются переменными в начале файла)
js/config.js        — имена, дата начала отношений, картинки по бокам
js/store.js         — хранение данных
js/app.js           — экраны и логика
assets/flowers/     — сюда кладутся твои картинки цветов для боковых панелей
```

## 3. Экраны

1. **Приветствие** (`#/`): внизу экрана — фото клумбы из Butchart Gardens (Vancouver Island),
   букеты-наклейки «стоят» в ней; цветок, «Привет, любимая», короткий текст, счётчик «мы вместе N дней»,
   выбор «кто сейчас здесь» (он / она) → переход в меню.
2. **Меню** (`#/menu`): 5 карточек.
   - 01 Наша история — *скоро* (фото, монолог, ИИ-видео)
   - 02 Галерея — *скоро* (случайные фото, загрузка обоими)
   - 03 **Хотелки** — сегодня
   - 04 **Наши цели** — сегодня
   - 05 **Календарь** — сегодня
3. **Хотелки** (`#/wishes`): оба могут добавить желание (текст, фото, ссылка).
   Фильтры: все / его / её / исполненные. Желание можно отметить исполненным или удалить.
4. **Наши цели** (`#/goals`): цель, описание, срок. Сортировка по сроку, подписи «осталось N дней»
   или «срок прошёл», отметка «достигли», прогресс-бар.
5. **Календарь** (`#/calendar`): сетка месяца (с понедельника), дни свиданий отмечены цветком.
   Нажимаешь на день и добавляешь свидание (что, время, где, заметка). Под сеткой список ближайших свиданий.

## 4. Дизайн

- Минимализм, много воздуха, кремовый фон, пудрово-розовый и шалфейно-зелёный акценты.
- Шрифты: *Cormorant Garamond* (заголовки, с кириллицей) и *Manrope* (текст).
- **По бокам** узкие колонки под цветы. Пока там нарисованная веточка (SVG); свои картинки ты укажешь в `js/config.js`.
  На телефоне боковые колонки скрываются.
