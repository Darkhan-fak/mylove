# mylove 🌸

Маленький сайт для нас двоих. Это статичный сайт, поэтому он бесплатно работает на GitHub Pages.

## Как посмотреть локально
Открой `index.html` в браузере, сервер не нужен.

## Как опубликовать
Settings репозитория → Pages → Source: *Deploy from a branch* →
ветка `claude/happy-knuth-7x937d`, папка `/ (root)` → Save.

Сайт: <https://darkhan-fak.github.io/mylove/>

Сборка запускается каждым push в эту ветку. Файл `.nojekyll` в корне нужен,
чтобы GitHub отдавал файлы как есть и не пытался собрать их через Jekyll.

## Где что менять
- `js/config.js`: имена, приветствие, дата начала отношений, подпись к клумбе,
  список наклеек по бокам.
- Наклейки лежат в `assets/stickers/`, их порядок задаётся в `config.js` в блоке `stickers`.
- `css/style.css`: цвета задаются в самом начале файла, в блоке `:root`.

## Общее хранилище (Supabase)

Записи хранятся в Supabase и общие для двоих. Что нужно сделать один раз:

1. В Supabase: **SQL Editor** → вставить `supabase/schema.sql` → **Run**.
   Он создаёт таблицы, закрытое хранилище для фото и правила доступа.
2. В **Authentication → Users** нажать *Add user* и завести две учётки с галкой
   *Auto Confirm User*. Почта берётся из `login` в `js/config.js`, а паролем
   служит день рождения ДРУГОГО в виде `ГГГГ-ММ-ДД`:
   - `darkhan@mylove.site` → пароль: день рождения Аиды
   - `aida@mylove.site` → пароль: день рождения Дархана

   Так войти может только тот, кто помнит дату своей половинки. Писем сайт не
   шлёт совсем: встроенная почта Supabase отдаёт пару писем в час.
3. В **Authentication → Sign In / Providers** снять галку *Allow new users to sign up*,
   чтобы посторонний не завёл себе учётку.
4. Обоим зайти на сайт со своей почтой и паролем.
5. Выполнить последний запрос из `supabase/schema.sql` — он добавляет обоих
   в таблицу `members`. Без этого записи не видны никому.

Читать и писать может только тот, кто есть в `members`. Публичный ключ в
`js/config.js` — не секрет: он лишь адресует проект, а доступ решают правила базы.

Если очистить `url` и `anonKey` в `js/config.js`, сайт вернётся к хранению в
браузере: работает без интернета, но каждый видит только свои записи.

## Проверка

- `node tests/qa.js` — весь сайт в браузере на трёх размерах экрана: приветствие,
  меню, хотелки с фото и фильтрами, цели, календарь, перезагрузка, смена
  пользователя. Гоняется в режиме браузера, без Supabase.
- `node tests/cloud.js` — облачный режим: библиотека на месте, вход по почте
  появляется.

Нужен установленный Playwright (`npm i -g playwright`).

Подробный план лежит в [PLAN.md](PLAN.md).

> ⚠️ Сейчас данные хранятся в браузере (`localStorage`): каждый видит только своё.
> Общие данные для двоих появятся на этапе 2 с Supabase.
