# mylove 🌸

Маленький сайт для нас двоих. Это статичный сайт, поэтому он бесплатно работает на GitHub Pages.

## Как посмотреть локально
Открой `index.html` в браузере, сервер не нужен.

## Как опубликовать
Settings репозитория → Pages → Source: *Deploy from a branch* →
ветка `claude/happy-knuth-7x937d`, папка `/ (root)` → Save.

Сайт: <https://darkhan-fak.github.io/mylove/>

Сборка запускается каждым push в эту ветку. Файл `.nojekyll` в корне нужен,
чтобы GitHub отдавал файлы как есть и не пытался собрать их через Jekyll.

## Где что менять
- `js/config.js`: имена, приветствие, дата начала отношений, подпись к клумбе,
  список наклеек по бокам.
- Наклейки лежат в `assets/stickers/`, их порядок задаётся в `config.js` в блоке `stickers`.
- `css/style.css`: цвета задаются в самом начале файла, в блоке `:root`.

## Проверка

`node tests/qa.js` прогоняет весь сайт в браузере на трёх размерах экрана:
приветствие, меню, хотелки с фото и фильтрами, цели, календарь, перезагрузку и
смену пользователя. Нужен установленный Playwright (`npm i -g playwright`).

Подробный план лежит в [PLAN.md](PLAN.md).

> ⚠️ Сейчас данные хранятся в браузере (`localStorage`): каждый видит только своё.
> Общие данные для двоих появятся на этапе 2 с Supabase.
